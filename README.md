## 德国 CN2 VPS 的「CN2」，先弄清是 GIA 还是 GT

标注了 CN2 的德国 VPS，体验可能差出一个档次，差别在回程走的是 CN2 GIA 还是 CN2 GT。

CN2 是中国电信的精品骨干网（AS4809），它分两档：GT（Global Transit）去程走 CN2，回程经常混走 202.97 开头的普通 163 骨干，晚高峰丢包明显；GIA（Global Internet Access）去回程都走 59.43 开头的高速节点，全程专属通道，晚高峰也稳。商家宣传页很少写清这一档区别，但延迟和丢包的差距就是从这里来的。

有个不用花钱的验证办法：拿到测试 IP 后跑一次回程路由追踪（traceroute），看回程节点是不是 59.43 开头。是，就是 GIA；混着 202.97，就是 GT 或者混跑。买之前先查商家的公开测评里有没有 59.43 节点的记录，比看宣传页靠谱得多。

另外提醒一句：宣传里写的「1Gbps」「500Mbps」只是机房端口速率的上限。实际能跑多少，取决于国际链路拥不拥堵、回程线路质量如何。端口数字大、回程走公共线路的机器，晚高峰照样卡成幻灯片。

## 写在条款里的几条限制，下单前必须知道

这些内容官网首页不显眼，但官方 FAQ 里都写得清清楚楚，直接决定你用起来顺不顺。

1. **超流量后的处理方式，两类套餐完全不同**。Nano、Storage、Performance 系列超量后端口被限速到 1–10Mbps，机器还在但基本没法用；其余套餐（含 Cloud）直接停机到月底。跑代理或下载业务的话，这个差别很重要——要么随时在后台加购流量，要么选 Performance 系列保住「停机但在线」的底线。
2. **流量双向计费**。1TB 指进加出合计，标称的 1TB 是保底承诺（guaranteed minimum），跑代理时按峰值的一半估算实际可用量。
3. **出站 25 端口默认封锁**（防垃圾邮件），要在这台机器上直接发信需要开工单申请，或者干脆把邮件交给专业服务商。
4. **BGP 会话和 IXP 端口要加钱**。法兰克福机房可以定制 BGP 会话和 DE-CIX、LocIX 端口，但需要额外设置费和月费，属于进阶玩法，普通建站用不到。

## 这类德国 VPS 适合谁、不适合谁

适合的情况：跨境电商管理欧洲站店铺（德国本地 IP + 稳定线路能降低平台关联风险）；面向欧美用户的建站或应用后端，同时希望国内访问不绕路；需要欧洲节点做远程办公中转。
